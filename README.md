# 🚀 DEV T.I. Consultoria - Landing Page & Dashboard de Vendas

Sistema completo de Landing Page para Consultoria de TI, integrando gestão de serviços dinâmica, painel administrativo seguro e checkout transparente via Stripe.



## 🛠️ Tecnologias Utilizadas

* **Frontend:** Bootstrap 5, HTML5, CSS3 (Modern Glassmorphism), JavaScript (Vanilla).
* **Backend:** PHP 8.x.
* **Banco de Dados:** MariaDB / MySQL.
* **Pagamentos:** Stripe API (Checkout Sessions & Webhooks).
* **Segurança:** PHP Sessions e Criptografia de senhas (password_hash).

## ✨ Funcionalidades Principais

### 🌐 Landing Page (Site Público)
- **Section Dinâmica:** Banner e informações de contato editáveis via painel.
- **Catálogo de Serviços:** Cards gerados dinamicamente a partir do banco de dados.
- **Checkout Integrado:** Botão "Contratar Agora" que inicia o fluxo de pagamento seguro.
- **Página de Sucesso:** Feedback imediato após a confirmação do pagamento.

### 🔐 Painel Administrativo (Acesso Restrito)
- **Dashboard de Vendas:** KPIs em tempo real (Faturamento, Vendas Pagas, Pendentes).
- **Gestão de Serviços:** CRUD completo (Criar, Ler, Atualizar, Deletar) em modais.
- **Controle de Conteúdo:** Edição de banner e contatos sem mexer no código.
- **Sistema de Upload Inteligente:** Processamento de imagens com limpeza automática de arquivos órfãos no servidor.
